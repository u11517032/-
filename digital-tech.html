數位科技概論 - 學習歷程與作業紀錄

HTML / CSS 網頁設計與 GitHub 版本控制實作

課程簡介

本課程專注於學習網頁前端基礎（HTML5 / CSS3）、多媒體整合、響應式網頁設計（RWD）以及網頁無障礙設計（Accessibility），並搭配 Git 與 GitHub 進行版本控制與網站發布。

學習單元與作業內容

  • 活動 01： 文字層級與語意標籤應用 (h1~h3, p, b, i, sub, sup)
  • 活動 02： 多媒體元件整合 (img, audio, video) 與多種圖片格式 (PNG, SVG) 操作
  • 活動 03： 學習計畫整理 (ul, ol, table)
  • 活動 04： 互動表單設計 (input, select, radio, checkbox, textarea)
  • 活動 05-09： CSS 樣式控制、版型規劃、卡片排列、RWD 響應式佈局與 WAVE 無障礙檢測

專案心得與收穫

透過實作學習，我掌握了如何將文字與媒體結構化，並使用 CSS 調整頁面佈局，最後透過 GitHub Pages 將作品發布上線，建立了個人第一個作品集網站！
